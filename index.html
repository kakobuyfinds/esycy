What to ask for in warehouse QC photos

Shoes

Request a photo of both size labels and an insole measurement. Compare the measured length with a pair that fits. Check both shoes for differences in color, shape, or visible damage.

Clothing

For tops, compare chest width and back length with a garment laid flat. For shorts, confirm whether the waist measurement is flat or stretched. Ask for a close-up if a seam, zipper, or print is hard to see.

Bags

Check the width against the largest item you plan to carry. Request photos of the strap attachment points, zipper, and inside lining before approving the parcel.

SuperBuy spreadsheet FAQ

What is a SuperBuy spreadsheet?

It is a product index shoppers can use to find and compare listings before buying through SuperBuy. This independent guide draws its product selection from HipoBuyFind.

What if the SuperBuy link no longer works?

Check the product’s Buy Link menu for the original seller listing. If the listing still opens and the agent accepts the item, paste the original URL into the agent’s order form and verify the item details before paying.

Is the catalog price the final amount I pay?

The CNY figure is a reference for the item. Add domestic delivery, agent fees, international freight, and any applicable taxes or duties to compare the delivered cost.

Can warehouse QC photos verify authenticity?

Warehouse photos can help you confirm visible features, measurements, and condition. For authenticity, verify the seller and request documentation that supports the product’s origin.
